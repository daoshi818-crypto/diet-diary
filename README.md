# 饮食日记

面向 Android 的中文饮食与营养记录应用。食物数据可离线使用，支持云端更新；饮食记录和个人档案保存在本机。

## 下载与更新

安装包在公共仓库的 [发布页](https://github.com/daoshi818-crypto/chiyoushu-food-data/releases/latest) 提供，手机无需登录 GitHub。应用内可在「设置 → 检查更新」检测、下载新版本，并交由 Android 系统确认安装。

当前仅构建 Android ARM64 正式版，使用本项目独立维护的签名。源码仓库保持私有，公共渠道只承担安装包、版本信息和食物数据的分发。

## 功能

- 中文食物搜索，支持空格分隔的多关键词、条码和自定义食物。
- 按克或毫升记录，常见分量可快速填充重量。单条食物选择餐次，待记录清单可混合多个餐次，也可修改用量。
- 文字描述记餐、食物照片识别、营养成分表识别；支持自定义 AI 地址、API Key 和从服务商获取模型。
- 可保存多食物组成的餐食，记录饮水、体重和运动。
- 热量目标与三大营养素目标分别设置；营养目标支持克重、供能比例及体重系数。
- TDEE 支持活动系数，或日常活动加每周有氧、力量训练均摊；常规运动避免重复增加摄入预算。
- 已记录食物可修改用量与营养成分，并同步更新当日合计。

## 数据与隐私

个人档案和饮食日志保存在本机。获取模型时会联系所填地址的模型列表；使用 AI 时将本次文字或照片发送至当前选择的供应商。自定义地址路径只联系用户填写的目标，不经过本项目另设的中转。API Key 保存在设备安全存储中，不写入食物库或公共发布信息。

公开渠道提供食物库、安装包与更新信息。AI 请求流程见 [AI 架构](docs/ai-architecture.md)，本次费用验证与准确性校验见 [调用优化](docs/ai-cost-optimization.md)。

## 开发与发布

Flutter 版本由 [.fvmrc](.fvmrc) 固定。依赖安装、代码生成和本地验证命令见 [AGENTS.md](AGENTS.md)。

推送 main 后自动执行检查并构建独立签名 APK；构建成功后生成版本、大小、SHA-256 信息并同步到公共发布渠道。食物库的导入和清洗工具见 tool/，数据说明见 data/。
