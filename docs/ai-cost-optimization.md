# AI 调用费用与识别校验

DeepSeek 官方地址由用户配置，模型仍从供应商列表选择，不自动替换模型。官方营养表提取使用关闭思考的 JSON 请求，省去强制工具调用不兼容后的重发；需要估计菜品营养的请求保留模型思考设置。其他服务商保留各自协议。

固定规则与结构放在 system 前缀，照片或用户描述放在最后，不拼入无关历史。DeepSeek 缓存由服务端尽力匹配，不能保证命中；不填充无用文字来增加命中率。

营养表结果在内存最多保留8条、15分钟。复用条件包含账号凭据摘要、供应商、地址、模型、提示词、结构、图片类型及图片字节摘要；同时请求合并，失败不保存。主动重新识别绕过已有结果。原图和密钥不写入此缓存文件或仓库。

识别必须返回选中列的原始标题。每份只有片数、没有质量或体积、标题包含净重或多列、数字与标题不一致时，基准留空，需要用户补全。缺失营养素保留空值；kJ/kcal、克/毫升、钠mg单独转换；未完成的模型输出拒绝使用。保存前展示原图与可编辑数值。识别存在误读风险，不承诺照片百分之百准确。

2026-11-22实测三张已知答案的合成图片，包括每100克和每30克并列、每250毫升与钠0.12克、每份2片且碳水缺失。OCR原始转录正确，但按当日价格，OCR+模型约2.37元/千次，旧视觉调用样本约1.63元/千次。加强校验后，三种样本的实际App接口测试通过。最后一轮960个输入token中768个缓存命中，燕麦表约0.62元/千次；同一请求按完全未命中估算约1.37元/千次；这只是小样本估算，不是实际账单保证。程序命中同图结果时不发新请求；主动重新识别照常计费。
